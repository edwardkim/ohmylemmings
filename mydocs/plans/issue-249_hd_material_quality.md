# HD 지형·지물 재질 완성도

담당 [#249](https://github.com/edwardkim/ohmylemmings/issues/249).

## 요청과 전수 점검

Mayhem08 강철 단색 표시를 계기로 현재 HD 지형·지물 전체에서 같은 종류의 미완성 표현을 찾아 개선한다. 기존 #215에서 수용된5재질·시설을 기준으로 강철·건설 계단과 원본 대체/누락·함정/장식/위험물/특수4장면을 점검한다.

점검은 현재 활성 catalog의 모든 object/frame 키와 실제 그림을 기준으로 한다. 디버그 fallback용 합성/구형 팩과 정상 전체 팩을 구분한다. UI 패널·미니맵의 기능상 단색 표시는 지형 질감 결함으로 취급하지 않는다.

## 구현·검증 원칙

- 강철/계단은 월드 좌표에 고정된 재질·이음·모서리/접촉 음영으로 개선하고 투명도와 실제 지형 경계를 보존한다.
- 함정·장식·위험물은 활성 자산의 누락/낮은 해상도/임시 도형 여부를 점검하고 발견한 결함을 함께 해결한다.
- 전수 점검에서 발견한 HD 지물/특수 배경의 nearest 확대는 프레임 내부 premultiplied bilinear 보간으로 바꾼다. 결정 테마의 평면 빨간 화살표는 기존 alpha/방향을 유지한 테두리 조명으로 보강한다.
- 원본 지형, steel/one-way/trigger mask, 판정, 입력과 애니메이션 frame 수·위상은 유지한다.
- TDD로 재질 변화·반복/스크롤·청크 경계·작은 구조물·mask 불변을 확인한다. 전후 캡처와 대표120레벨 초기 범위·모든54객체를 점검한다.
- Native, Canvas2D와 WebGPU가 같은 Rust draw-list/texture를 사용하게 유지하고 실제 화면으로 검증한다.
- 새 자산이 필요하면 출처/해시·팩/점진적 다운로드 선별을 함께 갱신한다. 불필요한 배포 자산은 추가하지 않는다.

공식 v0.3.4/Pages는 변경하지 않으며 이번 개발 결과와 검증을 별도로 기록한다.

구현과 재현 절차·시각 비교는 [결과 보고서](../reports/issue-249_hd_material_quality.md)를 따른다.
