# 플레이 타격감·조작 피드백 개선

담당 [#216](https://github.com/edwardkim/ohmylemmings/issues/216). 메인테이너가 전달한 실제 사용자 피드백5건이다. 승인된 #215 미술 수준은 기준으로 유지한다.

## 범위와 순서

1. 기술 사용 불가 안내와 원형 타깃: 수량0은 패널에서 명확히 비활성 표시, 수량이 있어도 대상 상태/강철 때문에 불가한 경우는 실제 적용 판정과 일치하는 표시·짧은 실패음을 제공한다. 포인터와 키보드 경로가 일치해야 한다. 선택 대상의 바닥 선을 몸 주위 원형 조준 타깃으로 교체하며, 색상만으로 가능/불가를 구분하지 않는다.
2. Digger 타격감·슉슉 굴착음: 원본 논리 타이밍/제거 범위와 실제 렌더링을 비교하고, 지형 제거 순간과 손동작/분진/소리를 맞춘다. 시뮬레이션 속도를 임의로 높이지 않는다. 성공적으로 굴착한 틱에만1회 발생시키고 동시 작업·pause/재시작·Web재생 제한·MP3/BGM 믹싱을 검증한다. 새 오디오의 출처/라이선스를 기록한다.
3. 추락사 표현: Fun02의 추락→충돌→사망 프레임을 캡처해 원본 동작 위상과 비교한다. 안전 착지와 구별되는 만화풍 충격·찌그러짐·먼지 및 기존 Splat음의 동기화를 검토한다. 치명적 높이/사망 타이밍/상태는 보존한다.

TDD, 공유 게임 표시/오디오 경로, 실제 Native/Web 동작·청취 확인, 사용자 인수, self-review/PR/정확한 CI를 완료 기준으로 삼는다. 신규 버전/공식 배포와 #113 성능 인수는 별도다.
