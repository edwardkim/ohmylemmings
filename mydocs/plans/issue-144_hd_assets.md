# #144 HD-03a 분리 걷기·암석 자산과 공통 팩

이슈: https://github.com/edwardkim/ohmylemmings/issues/144 · 상위 [#137](issue-137_2d_remaster.md)

메인테이너 다음 단계 승인과 main abd5fc8을 확인했다. [#138 아트 계약](issue-138_hd_art_contract.md), [#140 표시 계약](issue-140_hd_presentation.md)을 이어 첫 런타임 자산 경계를 구현한다.

1. 새 손그림풍 걷기 Right/Left 각8프레임과 독립 암석 재질을 image_gen으로 제작한다. 원본 그림을 확대하지 않으며 생성 PNG는 수정 없이 보존한다. 원본 slot0/2·frame0~7과 실제 atlas 사각형·표시 크기/발 기준점을 연결한다.
2. 오프라인 Python 도구가 제한된 PNG RGB/RGBA8을 CRC/필터/압축 크기까지 검증해 같은 픽셀의 RGBA 팩을 만든다. 입력 경로/해시·사각형·중복·범위와 과대 입력을 거부한다. 새 외부 의존 없이 합성 PNG로 TDD를 수행한다.
3. game crate의 `hd`에서 bytes를 빌리는 팩 로더·typed 프레임 조회를 구현한다. PNG/파일·플랫폼 의존과 시뮬레이션 변경을 추가하지 않는다. 버전/손상·잘못된 길이/크기·키/사각형·중복을 검증한다.
4. 실제 팩을 네이티브 probe로 읽고 WASM 라이브러리 컴파일·합성 검사를 수행한다. PNG/걷기 애니메이션과 발 기준점·6배 표시 크기를 확인하는 미리보기를 제공한다. 제작 품질과 실제 게임 통합 완료를 구분한다.
5. 출처·프롬프트·PNG/팩 규격/해시·상태별 커버리지를 기록하고 필요한 로컬/실제 CI·self-review 후 병합한다.

이번 범위는 걷기2슬롯/16프레임·암석1종과 팩 경계다. 입출구·굴착/계단/폭발·UI는 HD-03 후속이고 실제 HD 화면/입력·GPU는 HD-04다. 전체337프레임/5테마·실제 HD 모드의 완료로 표시하지 않는다. 생성 기준을 충족하지 못하면 재제작 또는 미검증을 명시한다. #113 성능 이월·저사양60fps 반복 중단, #1 CLOSED·공개 v0.1.0/Pages·Windows11 지원 정책을 유지한다. Chrome156 CI 진단은 #142 별도 후속이다.
