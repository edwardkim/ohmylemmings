# #137 2D HD 리마스터

이슈: https://github.com/edwardkim/ohmylemmings/issues/137

메인테이너가 원본 픽셀 확대의 거친 표현을 개선하기 위해 그래픽 리소스를 함께 고화질 디자인하도록 지시했다. 초기 구현의 #1은 완료 상태를 유지하며 이 문서가 새 기능의 상위 계획이다.

## 목표와 현재 상태

1920×1080급 화면에서 새 캐릭터·지형·시설/효과·UI를 HD 해상도로 합성한다. 기존 논리 틱·레벨·충돌·지형 변형·저장 입력·사운드 사건은 보존한다. 원본 모드도 유지한다. 부드러운 손그림풍2D를 첫 시각 후보로 사용하며 사용자의 스타일 선택을 우선한다.

첫 절편 [#138](https://github.com/edwardkim/ohmylemmings/issues/138)의 [Fun 01 시안·규격](issue-138_hd_art_contract.md)과 [결과](../reports/issue-138_hd_art_direction.md)를 준비했다. 시안 그림 자체는 제작 참고이며, 이후 별도 Native/Web 부분 HD 게임과28/337 캐릭터 자산을 구현했다. 특수 장면/나머지 시설/효과/UI·지원 HD 배포가 남아 #137은 OPEN이다.

## 렌더링 경계

- 논리 게임 영역은320×160, 초기 HD 게임 영역은1920×960의6배 대응이다. 나머지1920×120은 새 HD 패널이다. 기존320×200 프레임은 원본 모드에 보존한다.
- 시뮬레이션·자원 파서와 플랫폼 어댑터를 분리한다. 코어에 PNG·GPU·파일/브라우저 의존을 추가하지 않는다.
- HD renderer는 공통 세션에서 읽기 전용 표시 자료를 받는다. 그림·UI·보간 결과를 충돌/진행/입력 판정에 되먹이지 않는다.
- PNG/atlas·지형 mask·고정 기준점·애니메이션 상태의 검증된 명세를 Native/Web이 공유한다. 기존 진단 JSON의 Debug 문자열을 새 제품 API로 간주하지 않는다.
- 생성 시안의 지형 윤곽은 제작 참고이다. 실제 지형 경계·굴착·계단·철/일방통행은 기존 마스크가 기준이다.
- HD 합성은 GPU 활용과 변경 구간 갱신을 우선 검토한다. 전체 고해상도 맵을 매 표시마다 CPU로 재합성하는 구조의 비용을 별도로 검증한다.

## 인수와 배포

첫 통합 레벨은 Fun 01이며 일반 걷기 외에 저장 입력/합성 사례로 굴착·계단·폭발을 검증한다. 전체 상태/레벨 전개는 HD-05 이후이다. UI는 원본의8직업·생성속도·Pause/Nuke·미니맵·결과/재시작 기능을 모두 제공해야 한다.

Windows는 Windows 11 x64만 지원한다. Mac ad-hoc/미공증과 원본/제3자 고지는 기존 정책을 따른다. 공개 v0.1.0 태그/asset/Pages를 이 작업에서 교체하지 않으며, 새 배포는 기존 버전·태그 정책으로 별도 검증한다.

#113은 기존 모드의 고성능 호스트 성능/메모리 후속이다. 현재 저사양 호스트의 긴60fps 반복은 재개하지 않는다. HD 모드의 새 성능 요구·환경·자료는 별도로 기록하며 기존 미충족 수치를 통과로 바꾸지 않는다.

## 메인테이너 작업 우선순위

2026-10-23 지시: **2D 리마스터 #137을 먼저 완료하고, 이후 BGM #165를 수정한다.** #165의 원인 조사 결과는 보존하지만 리마스터 진행 중 제품 수정을 시작하지 않는다.

남은 순서:
1. 약2.4MiB의 현행 팩 여유를 고려한 자산 로딩/분할 방식을 정리한다.
2. 특수4장면과 나머지 함정·효과를 HD로 대응한다.
3. 글꼴·전체 UI/결과 화면을 완성하고 자산 누락을 확인한다.
4. Native/Web 원본 규칙·입력·화면 회귀, 지원 HD 패키징·출처/고지·설치 인수를 마쳐 #137을 완료한다.
5. 그 다음 #165의 공통 OPL buffered delivery 구현과 지속 BGM/효과음 병행·플랫폼/청취 검증을 진행한다.

BGM 결함은 알려진 별도 후속으로 명시하며, HD 검증 통과를 BGM 정상 판정으로 확대하지 않는다. #113 성능 이월과 공개 배포의 버전/태그 정책은 유지한다.
