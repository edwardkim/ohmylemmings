# #138 Fun 01 HD 시안·자산/표시 계약

이슈: https://github.com/edwardkim/ohmylemmings/issues/138 · 상위 [#137](issue-137_2d_remaster.md)

## 첫 시각 후보

[Fun 01 손그림풍 시안](../../assets/remaster/concepts/issue-138_fun01_handpainted_v1.png)은 built-in image_gen으로 새로 생성했다. 실제 캡처는 지형 배치와 캐릭터 크기의 참고이며 원본 캡처 바이트는 ignored assets/local에만 보관한다. 시안은1672×941이고 목표1920×1080의 최종 런타임 자산이 아니다. 생성 프롬프트와 실제 규격/해시·검토 결과는 [manifest](../../assets/manifests/remaster_art_direction.json)에 기록한다. 스타일은 첫 후보이며 사용자 확정 판정을 대신하지 않는다.

색·조명은 따뜻한 암석/초록 이끼와 어두운 동굴의 대비를 사용한다. 레밍은 작은 체격·초록 머리·파란 옷·또렷한 발/도구로 구분한다. 지형 재질의 세밀함이 길·철·일방통행·위험물의 식별을 가리지 않게 한다.

## 1920×1080 기준 배치

| 영역 | HD 좌표 x,y,w,h | 입력/표시 역할 |
|---|---|---|
| 게임 | 0,0,1920,960 | 논리320×160을6배 대응. 화면비/시야 폭 유지 |
| 상태 | 0,960,400,120 | 레벨·인원·구출/목표·시간·선택 상태 |
| 생성속도2버튼 | 400,960,160,120 | 기존 누름/반복 동작 유지 |
| 직업8버튼 | 560,960,832,120 | Climber/Floater/Bomber/Blocker/Builder/Basher/Miner/Digger 순서. 각104폭 |
| Pause/Nuke | 1392,960,176,120 | 각88폭, 기존 Nuke 두 번 클릭 규칙 유지 |
| 재시작 | 1568,960,88,120 | 기존 재시작 사건 연결 |
| 미니맵 | 1656,960,264,120 | 맵·시야/카메라·드래그, 실제 내용 영역/여백 분리 |

이 표가 제작/구현 계약이다. 생성 그림의 버튼 좌표·글자·개수·선택 효과를 입력 규격이나 실제 상태 값으로 읽지 않는다. 버튼 안쪽의 글자/아이콘·상태줄은 HD에서 별도로 그린다. 변경된 디스플레이 비율에서는1920×1080을 비율 유지해 배치하고 출력 여백은 입력 대상에서 제외한다. OS 배율·실제 drawable 크기와 CSS 좌표를 구분한다.

HD 게임 영역의 점 `(sx,sy)`는 `[0,1920)×[0,960)`에서만 논리 `(floor(sx/6),floor(sy/6))`로 변환한다. HD 패널은 새 영역별 명령으로 변환하며 단순히 원본320×200 좌표로 축소하지 않는다. 카메라는 기존 논리 단위를 유지하고 레밍 선택/직업 할당은 기존 판정을 사용한다.

## 캐릭터·애니메이션

[원본 목록](../../assets/manifests/lemming_sprites.json)의28애니메이션337프레임을 빠짐없이 대응한다. HD 자산 이름은 상태·방향·frame으로 고정하고 원본 slot/frame, 실제 HD 사각형·발 기준점·투명도와 연결한다. 공유/방향별 슬롯을 임의로 합치지 않는다.

HD에서 발 위치는 `(6*(actor.x-camera),6*actor.y)`이며 그림의 좌상단은 이 점에서 각 자산의 HD 발 기준점을 뺀다. 좌우 반전·trim·padding 시 기준점도 함께 변환한다. 첫 제작 크기는 원본16×10 캐릭터 기준96×60 캔버스 등을 사용하되 실제 크기·anchor를 명시한다. 프레임/상태 전환의 논리 틱과 도구가 지형에 닿는 사건은 변경하지 않는다. 추가 보간은 표시 전용이다.

PNG RGBA8/sRGB를 제작 교환 형식으로 사용하고 게임 글자·숫자는 그림에 굽지 않는다. atlas는 분리 자산이 검증된 뒤 구성하고 투명 테두리·필터 경계 누출·색 번짐을 확인한다. PNG 해제/플랫폼 전송과 시뮬레이션의 의존을 분리한다.

## 지형·시설·효과

원본5세트273지형·54객체종·객체 애니메이션540프레임/미리보기54개, 특수4장면을 제작 범위로 추적한다. [전체 대응 목록](../../assets/manifests/remaster_art_direction.json)의 runtime 자산은 현재 모두 미착수다.

지형 재질·암석 단면·이끼/표면과 충돌 마스크를 분리한다. Digger/Basher/Miner/Bomber의 삭제 영역과 Builder의 추가 영역은 기존 mask의 동일 변경에서 갱신한다. 장식·안티앨리어싱·그림자는 별도 표현이며 통과 가능한 틈을 막거나 실제 지면을 숨기지 않게 한다. 철/일방통행의 시각 구분도 물리 의미와 연결한다.

입구·출구·함정은 원본 기준점·trigger·재생 phase·앞/뒤 지형 clipping 규칙을 유지한다. 물/불·폭발/입자·카운트다운·성공/실패는 필요한 상태와 프레임을 따로 제작한다. 고해상도 맵은 chunk와 dirty 영역을 사용해 지형 변형/카메라 변화의 갱신 범위를 제한한다.

## 구현 전 검토 결과

시안은 부드러운 재질·캐릭터 크기와 위층→오른쪽 낙하→아래층 출구의 흐름을 검토할 수 있다. 실제 mask와의 픽셀 일치는 검증하지 않았고 보장하지 않는다. 캐릭터·지형·시설·패널이 한 그림에 합쳐져 있으므로 런타임에서 사용하려면 분리 제작이 필요하다.

시안의 CLIMB 아이콘은 걷기처럼 보이고 생성속도/Nuke 버튼이 빠져 있다. 실제 제작에서는 위 UI 계약과8직업 의미에 맞춰 수정한다. 시안의 패널 높이·문자/숫자도 제품의 정확한 위치/상태로 간주하지 않는다. 최종 레이어는 목표 해상도로 새로 제작하고 단순 이미지 확대를 제작 완료로 세지 않는다.

첫 시안 이후 실제 한 레벨 통합에서 걷기·굴착·계단·폭발·출구/패널 입력을 검증하고, 상태/지형/입력/사운드의 원본 모드 동일성과 Native/Web 표시를 확인한다. 전체 HD 모드·전체 자산의 완료는 상위 #137에서 추적한다.
