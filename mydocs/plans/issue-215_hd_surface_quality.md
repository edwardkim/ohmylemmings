# HD 지형·지물 시각 품질 개선

담당 [#215](https://github.com/edwardkim/ohmylemmings/issues/215). 메인테이너가 낮은 질감을 지적하고 개선을 요청했다. [#137](issue-137_2d_remaster.md)의 최초 HD 기능 구현 완료와 구분하는 후속이다.

- 기존 손그림풍2D와 충돌/파괴 형상·트리거/객체 위상·원본 모드·게임/사운드 규칙을 보존한다.
- 현재1254px 재질이256HD px로 축소 반복된다. 재질의 크기/반복 스케일과 평평한 경계를 대표 장면에서 분리해 검토한다. PNG 해상도 증가만으로 완료 처리하지 않는다.
- 대표 암석/흙과 입출구를 먼저 같은 카메라/틱에서 비교해 미술 방향을 확인한 뒤5테마/지물로 확장한다. 대표 장면 인수를 전체 범위 완료로 표시하지 않는다.
- 큰 암석 형태·중간 균열·작은 입자, 지형/굴착면의 깊이와 시설의 돌/목재/금속 재질·접지·대비를 개선한다. 시각 장식으로 충돌 밖의 바닥이나 숨겨진 위험을 만들지 않는다.
- built-in image_gen의 새 자산은 새 파일로 보존하고 정확한 프롬프트/출처/해시를 기록한다. 생성 PNG 임의 리터치/원본 그림 확대 대체를 하지 않는다.
- 샘플링/합성은 TDD로 바꾸며 지형 변경·청크 경계·스크롤·강철/계단·객체 clipping/위상과 상태/맵/사운드 동일성을 확인한다.
- 실제 Native/Web1920×1080과 초기 다운로드량/FPS 표시를 검토한다. #113의 중단한60초 반복/고성능 환경 성능 인수를 대신하지 않는다.
- 실제 플레이 피드백·self-review·문서/일지·PR/정확한 CI·병합을 기록한다. 공개 태그/릴리즈/Pages와 기존 미리보기는 보존한다.

## 형태와 재질의 조화: 메인테이너 피드백 반영

Fun02의 텍스처 향상은 확인되었으나 직선 기둥과 거친 암석 재질이 부조화라는 피드백을 받았다. 다른 레벨도 같은 기준으로 검토한다. 재질 해상도/반복 주기 개선만으로 시각 완성도를 인수하지 않는다.

- 기둥은 상부 판석·몸통·받침, 자연 암석은 덩어리·파단면, 대리석 구조물은 판재·모서리·단면으로 구분한다. 모든 경계에 임의 노이즈를 넣는 방식은 사용하지 않는다.
- 얇은 발판과 좁은 통로는 전용 표현이 필요하다. 강철·계단은 별도 재질을 유지해 파괴 가능 여부와 보행면을 읽을 수 있어야 한다.
- 일반 지형의 단일 재질 채우기를 보완할 배치/지형 조각 기반 표시 정보를 검토한다. 기존 LevelRecord의 terrain ID/배치와 HD 표시 경로를 사용하고 simulation에는 미술 의존성을 넣지 않는다.
- 충돌/보행 높이·좁은 통로·파괴 결과를 유지하며 모서리/옆면을 개선한다. 표시 윤곽이 실제 판정과 어긋나 숨은 벽·보행면을 만드는 변경은 채택하지 않는다.
- Fun02 기둥을 첫 실제 비교 대상으로 삼고 Fun03 얇은 발판, Fun08 장식 기둥, Fun12 강철/벽, 나머지 테마와 특수 장면으로 회귀한다. 전체120레벨 검토와 대표 장면 검토를 구분한다.
