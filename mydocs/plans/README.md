# 계획 문서

분할정복 기반 목표와 의존관계·완료 기준은 [전체 구현 계획](implementation_plan.md)에서 관리합니다.

- 단계별 목표, 구현 범위, 모듈 간 의존성, 완료 기준을 기록합니다.

- 진행 상태는 실제 구현과 검증 결과에 맞춰 갱신합니다.

파일명 예: `phase_1_foundation.md`.
