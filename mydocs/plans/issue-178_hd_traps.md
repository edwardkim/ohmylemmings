## 조사와 대응

10객체159프레임이다: 세트0의6/8/10(15/17/12), 세트2의8(15), 세트3의8/9/10(37/7/7), 세트4의7/9/10(25/8/16). 모두 first0·once/effect4이며 원본 trigger·sound ID를 보존한다. 함정 그림에 포함된 포획 캐릭터도 새 디자인으로 대응한다. 특수 강하 추·대리석 압착기·케이블 장치·양방향 벽 가시·전기/광선 장치를 구분한다.

TDD로 전체159키/누락·경계와 실제 TrapStates 프레임·재사용·Pause 중 정지/그리기 무부작용을 검증한다. 기존 렌더러의 압축 인덱스(입구 제외, 비함정 포함)와 함정 상태 선택을 유지하고 HD/원본 프레임 진단만 추가한다. 새 합성 코스는 앞선 비함정1개와 같은 함정2개를 배치하여 ID/인덱스 혼동과 인스턴스별 위상을 검사한다. 정상/Pause 총20코스를 SDL 원본/HD와 WASM/Canvas에서 매 상태 대조한다.

새 PNG는 원본 출력 그대로 보존하며 실제 프레임 사각형/표시 크기/앵커를 명시한다. 카탈로그 확장으로 기존39page와 RGBA를 보존하고25scope의128MiB/32page 한계를 확인한다. 원본120초기 장면과 선택 틱·기존14위험 사례/다른 Web 회귀·출처 감사·self-review와 CI를 거쳐 실제 병합한다.
