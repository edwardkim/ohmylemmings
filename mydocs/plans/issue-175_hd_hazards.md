# #175 물·불 위험 요소 HD

이슈: https://github.com/edwardkim/ohmylemmings/issues/175 · 상위 #137

원본 물/불 객체의 프레임·표시 크기·위험 trigger·순서/클리핑을 조사하고 새 그림을 연결한다. 시뮬레이션·음악 합성은 바꾸지 않는다. TDD와 Native/Web 위험 사건/화면 검증, 출처·프롬프트·해시, 감사·self-review·CI·실제 병합으로 완료한다. 기계 함정·나머지 장식/효과·전체 UI는 후속이다. 사용자 CDP19222/8080과 preview-172를 유지한다.

## 원본 대응과 구현

GROUND0O..4O의 effect5/6만 대상으로9객체84프레임을 등록한다. 슬롯별 프레임 수는8/10/16으로 제한하고 누락·범위 초과를 거부한다. 출구 불꽃·횃불·기계 함정과 구분한다. 세트2/9는 effect6이지만 그림은 전기/회전 장치이므로 형태를 보존한다. PNG8장과 원본 메타데이터/프롬프트/해시는 `assets/manifests/hd_hazards.json`, 카탈로그 확장은 `remaster_hazards.json`에 고정한다.

렌더러의 기존 Object 키와 프레임 선택/뒤집기/원본 그리기 순서를 사용한다. 공통/테마별 페이지 선택으로25조합의128MiB/32page 제한과 기존31page 동일성을 검사한다. 부족한 팩은 기존 그림으로 fallback하며, 진단에 HD/원본 위험 키를 노출한다.

검증: TDD(잘못된 키·누락·전체84위상·그리기 무부작용), 새9개 합성 코스의 SDL/WASM 사망/상태/마스크/사운드 대조, 원본120초기 장면·선택 틱, 기존 위험 행동 회귀, 자산 픽셀·출처 감사, self-review·CI·실제 병합. 전체 리마스터·레벨 완주·성능 인수는 후속 범위다.
