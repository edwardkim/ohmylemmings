# 진행 중 작업

현재 작업의 진행 상태와 이어서 작업하는 데 필요한 컨텍스트를 관리합니다.

- 담당 이슈와 관련 계획, 날짜별 작업일지, 피드백 문서를 연결합니다.
- 작업 목표, 완료한 내용, 현재 시도와 설계 결정을 기록합니다.
- 미해결 문제와 다음에 할 일을 갱신합니다.
- 작업 완료 시 결과를 `reports/`에 정리하고 해당 보고서를 연결합니다.

파일명: `issue-<번호>_<주제>.md`. 예: `issue-2_dos_baseline.md`.
