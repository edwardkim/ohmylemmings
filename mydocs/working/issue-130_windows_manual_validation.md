# #130 Windows 10/11 사용자 PC 수동 검증

이슈: https://github.com/edwardkim/ohmylemmings/issues/130

## 최신 상태 — 메인테이너 인수 / 2026-10-22

메인테이너가 Windows 11·웹브라우저에서 직접 테스트하고 성공 판정을 보고했다. 이 판정을 #130 완료 근거로 수용하고 [결과 보고서](../reports/issue-130_maintainer_acceptance.md)에 원문과 범위를 기록한다. Windows 10은 미검증이며, 개별 검사 항목·환경·버전/ZIP 해시의 상세 정보는 보고되지 않았다. #113 성능/메모리와 #1/G11/G12 전체는 미완료로 유지한다.

문서·일지·상위 추적을 동기화하고 self-review·문서 검사를 거쳐 PR 실제 병합 후 종료한다. 최종 병합 기록은 GitHub 이슈를 따른다.

## 초기 이관 기록

아래는 #115에서 이관한 당시의 계획과 미검증 상태이다.

#115 종료 정리에서 이관한 OPEN 후속이다. #118의 packager/런처·원본28개·실제 Windows CI와 사용자의 게임 실행 확인은 완료된 근거로 보존한다. Windows10/11 각각의 일반 PC 키/마우스·배율·물리 청취 기록은 아직 확보되지 않았다.

초기 대상은 v0.1.0 Windows x64 ZIP, SHA256 44fef8d9c20b4396a37b910353899b80307c5e6c5472f473d5d859392fbde138이다. OS build/아키텍처/배율·그래픽/음향 환경과 버전/해시를 고정해 새 폴더 압축 해제/더블클릭, 원본 화면/기술 패널, 키·마우스·카메라/미니맵·일시정지, 음악/효과음 청취·음소거/음량, 결과·재시작/다음 레벨을 확인한다. OS별 결과와 결함 재현을 기록한다.

완료 목록은 이슈 본문을 따른다. runner의 비영 PCM을 사람의 청취로 대신하지 않는다. 이번 이관에서 실제 PC 검사를 수행하거나 #113 성능 반복을 시작하지 않았다. 화면/PCM·원본/개인 자료는 Git에 넣지 않는다.
