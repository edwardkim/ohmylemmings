# G08-02 위험물·함정 진행 기록

이슈: [#50](https://github.com/edwardkim/ohmylemmings/issues/50), 상위 [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 착수

사용자가 다음 절편을 승인했습니다. main e1e1b1d·원격 동기화·깨끗한 작업 트리와 선행 #48/PR #49를 확인하고 #50 번호/URL/OPEN 검증 후 전용 브랜치에서 착수했습니다. 물/불/작동형 함정의 판정 순서·사망 애니메이션·객체 재사용을 원문에서 확인하고 TDD→기준/합성/원본·DOS 관측→전체 회귀→문서/자체 검토/PR/정확한 CI/병합/종료 순서로 진행합니다.

승패/재시작·원본 패널·포인터/우클릭·음향은 후속입니다.

## 구현·검토

물/불 사망 상태와16슬롯 함정 런타임·원본 프레임·hazards.jsonl/traps.bin을 연결했습니다. 코어14·세션2·Python4 테스트를 추가했습니다. API/모듈 누락 Red→Green 뒤 검토에서 사망 중 타이머의 OhNo 분기를 발견하고 실제 실패를 확인해 즉시 Exploding으로 수정했습니다. DOS의 Y>=160 트리거 차단도159/160/163 경계와 저장 Blocker 맵 참조 오류로 고정했습니다.

실제54함수·표로 최종14사례/28재생11788상태·1714캡처가 일치했습니다. 원본 Fun09/17/29 렌더1/7·실시간9재생과 실제 Fun17 Pause241/Resume252를 각각 대조해10재생3410상태/797캡처가 일치했습니다. 검토 전 합성1/2·원본1을 더하지 않고 최종3/2를 보존합니다. 기준 호스트1/2는 자체 선언/FPC 변환 실패이며 성공은3입니다.

원본 코드 입력으로 DOS Fun09/17/29를 열고 무수정 원본50개·별도 생성 RUSSELL seed를 검증했습니다. 최초 함정1은 수치 관측 성공이나 코드 문자v/녹화 키 충돌로 제외하고 녹화 키를F11로 분리했습니다. 최종 함정2/3·물1·불1에서 사망/프레임을 관측했고5장면×2+4+4=18개 전체 게임 화면이 일치했습니다. 최종 네이티브 RGB 바이트의 일치로 수정 후 실행과도 연결했습니다. 전용 Xvfb/자식 프로세스는 종료했습니다.
