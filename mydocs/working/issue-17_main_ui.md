# G03-08 MAIN.DAT UI·폰트 진행 기록

작업 이슈: [GitHub #17](https://github.com/edwardkim/ohmylemmings/issues/17). 상위: [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 범위와 순서

번호·URL·OPEN 상태를 먼저 확인했습니다. 고정 소스·원본 레이아웃 분석 → 합성 Red/Green → 무할당 API → 지원 이미지/글리프 전체 독립 대조 → 문서·검사·게시·실제 CI 순서로 진행합니다.

UI·폰트·메뉴 이미지 리소스를 해석합니다. 화면 조립·입력·HUD 규칙·문자열 배치·변형 마스크·객체 합성은 후속 범위입니다.

## 현재 상태

UI 구간·이미지·글리프 API와 호스트 예제·검증 매니페스트를 구현하고 로컬 검증을 마쳤습니다. [기술 계약·재현 명령](../tech_insights/issue-17_main_ui.md)과 [결과 보고서](../reports/issue-17_main_ui.md)를 작성했습니다. 게시·실제 CI·원격 파일 대조 후 이슈를 완료합니다.

## 수행과 근거

- 원본 50개·기존 소스 46개의 해시와 새 고정 소스 7개의 크기·git blob·SHA-256을 확인했습니다.
- 새 합성 16개 실패·기존 리소스 135개 통과의 Red 이후 Green 151개를 확인했습니다.
- `make check`: Rust 단위 153개·문서 예제 12개·Python 8개, 포맷·Clippy·빌드·WASM 성공.
- 원본 MAIN을 독립 Python으로 직접 해제해 기존 7개 구간의 모든 바이트·해시를 유지했습니다.
- 19개 묶음·200개 이미지/글리프·216192개 색상/점유 픽셀이 Rust·Python·실제 TS와 일치합니다. TS 실제 UI 조회 72개와 Lemmix 레이아웃/실제 TS 디코더 128개를 구분해 RGB·알파·점유도 확인했습니다.
- 패널/글꼴의 불투명 0, 전체 스크롤 프레임·메뉴 글꼴·숫자 교차 stride와 미해석 원문 보존을 기록했습니다.
- CLI 오류 16개에서 경로·기존 출력/원본 보존을 확인하고 UI 미리보기를 검토했습니다. 문서 재현 명령을 그대로 실행해 7개 구간·200개 픽셀 해시를 확인했습니다.
- Markdown 66개·로컬 링크 441개·앵커 74개·이슈 문서명 54개·#17 일지·고정 입력 4개·추가 소스 12개·기존 로컬 의존 하나를 확인했습니다. 앞 단계 매니페스트는 변경하지 않았습니다.

구현·문서 게시 → 실제 CI → 원격 파일 대조 → 최종 문서 게시·CI → 상위 #1 갱신·#17 종료 순서로 마칩니다. G03 전체는 마스크·카운트다운과 객체 합성이 남아 진행 중이며 다음은 새 이슈의 G03-09 MAIN.DAT 마스크·카운트다운 해석입니다. G04-01도 준비 상태입니다.
