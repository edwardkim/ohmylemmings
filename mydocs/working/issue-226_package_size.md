# 배포 용량 최적화 진행

담당 [#226](https://github.com/edwardkim/ohmylemmings/issues/226), [계획](../plans/issue-226_package_size.md).

- 대응 소스에서 현재 runtime atlas/provenance/extension 경로에 없는 미술·디자인 프리뷰, 과거 보고서/이미지, 현재 버전 외 릴리즈 노트, 과거 측정/재생 JSONL을 제외한다. 현행 소스·테스트·빌드 스크립트·설정·고지·폰트·아이콘·현재 미술 원본은 보존한다. 저장소의 역사 자료 자체는 삭제하지 않는다.
- 정식 게시 시 검증된 CI 패키지에서 소스만 분리해 기존 공통 source.tar.gz 릴리즈 자산 하나로 연결한다. 플랫폼별 패키지에 canonical 버전 URL·크기·SHA·재빌드 안내를 포함한다. macOS .app 내부는 변경하지 않아 서명된 바이트를 보존한다.
- 검증기는 별도 소스 누락/불일치·외부 URL 변조·런타임 변조를 거부한다. Pages는 별도 소스를 검증하되 사이트에 중복 복사하지 않는다. 과거 내장 소스 패키지는 계속 검증 가능하다.
- Web 빌드의 오래된 content-addressed HD 캐시 파일만 정리한다. 임의 사용자 파일/심볼릭 링크는 삭제하지 않는다. 원본 모드·HD 53페이지·폰트/아이콘·라이선스는 실제 사용 중이므로 제외하지 않는다.

검증 진행: Python338개 통과, 네 플랫폼 합성 패키지의 런타임 바이트/권한 유지·외부 소스 검증·Pages 분리 테스트 통과. 축소 소스만 추출한 환경에서 WASM/Native release 빌드 성공, HD56파일97,004,652바이트가 v0.3.2와 동일함을 확인했다. 1차 소스 묶음은120.5→86.6MB이며 이후 과거 로그/노트 제외도 반영했다. 최종 실제 패키지 크기·실행·CI는 후속 보고서에 기록한다.

개인 증거는 ignored `assets/local/issue-226-review/`에만 둔다. 공식 v0.3.2 파일/Pages와 사용자19222/8080은 변경하지 않았다. 버전 게시 선택은 사용자에게 별도로 확인 중이며 구현/검증은 계속한다. #113 성능 NOT READY와 원본 자산의 권리 경계는 유지한다.


## 정식 게시 사전 검증 보정

PR#227/CI40140861375의7개 플랫폼 검사는 통과했다. main5fab0fa에서 prepare-only40142262227은 각 플랫폼의 실제 소스 파일 내용이 일치함을 확인한 다음, 압축 컨테이너 전체 바이트 일치 검사에서 중단됐다. 공개 게시/Pages는 실행하지 않았다.

소스 내용 비교를 유지하면서, 게시 호스트가 해당 tree에서 생성한 대응 소스 아카이브 하나로 정규화하고 모든 패키지의 소스 hash/크기/안내를 그것에 맞추도록 보정한다. 압축 헤더가 다른 동일 소스를 허용하되 내용이 다른 소스는 거부하는 회귀 테스트를 추가했다. 수정한 정확한 소스의 CI와 prepare-only를 다시 검증한다.
