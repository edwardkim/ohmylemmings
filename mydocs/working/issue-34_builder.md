## 범위와 현재 상태

2026-10-19에 GitHub CLI 인증을 완료하고 #34의 번호·URL·OPEN 상태를 조회해 확인했습니다. G00~G06과 #31~#33 완료 후 Builder의 구현·검증·자체 검토를 마쳤습니다. 준비 작업은 사용자 요청대로 개발 이슈에 포함하지 않습니다. 기존 미추적 폴더는 보존합니다.

Builder 할당·12개 벽돌·Building/Shrugging·양방향 지형 추가·충돌/경계·기존 세 직업 전환과 네이티브 선택/입력/재생/화면을 구현합니다. 코어의 no_std와 플랫폼/리소스 의존 방향을 유지합니다. G07 전체·완주/승패·음향·전체 DOS 인증은 후속입니다.

## 확인한 기준과 다음 행동

- 고정 Lemmix `40e9bc34451f0e9127fd53b290a3877e700d143d`의 `Game.pas`에서 AssignBuilder·LayBrick·HandleBuilding·HandleShrugging·Transition을 읽었습니다. Building은16프레임/FootY13, Shrugging은8프레임/FootY10입니다.
- 프레임9와 벽돌9개일 때의 프레임10에6픽셀을 빈 곳에 추가하고, 프레임0에수평2/수직-1 이동·벽돌 소비·충돌/소진/상부 경계를 처리합니다. 실제 Pascal 함수를 실행해 계약을 검증합니다.
- 먼저 코어 정상/거부·양방향·프레임·전체 계단·충돌·전환·오류/배치 테스트를 Red로 확인한 뒤 구현합니다. 네이티브 입력/지형 추가 기록과 기준 호스트를 이어서 검증합니다.
- 원본·참조 사본·다운로드 바이너리·전체 추적/영상/화면은 ignored `assets/local/`에 둡니다. 검증 결과와 미검증 항목을 분리해 보고합니다.
