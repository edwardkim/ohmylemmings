## 착수와 계약

사용자가 다음 절편을 승인했습니다. main `4616c5e`·깨끗한 작업 트리·열린 작업 이슈 없음을 확인하고 #48 번호/URL/OPEN을 검증한 뒤 전용 브랜치에서 착수했습니다. 루트 지침과 G08 착수 계획·호환성 기준을 읽었습니다.

고정 Game.pas의 Start/InitializeObjectMap/CheckForInteractiveObjects/CheckLemmings/HandleExiting/RemoveLemming/Transition을 확인했습니다. 입구를 제외한 ObjectInfos의0..15번까지 객체 맵을 덮어씁니다. 출구 코드는129이며 Falling만 진입을 거부합니다. 낙하의 착지 직후 Splatting도 같은 틱에 Exiting으로 바뀔 수 있고 정지 방향을 유지합니다. Exiting은8프레임 Once·발 기준13이며 끝에서 제거와 구출을 함께 집계합니다. 판정 중에는 다른 객체를 다시 검사하지 않습니다. 타이머는 진입 시 취소하지 않으므로 일반 Bomber/Nuke와의 순서를 보존해야 합니다.

코어 TDD→네이티브 원본/합성 연결→실제 고정 함수 실행·합성/원본 재생·기존 회귀→보고/자체 검토·PR/정확한 CI·병합/main CI 순서로 진행합니다. 위험물/함정·승패/재시작·하단 패널·포인터 선택/우클릭 버그·음향은 후속 절편입니다.

## 구현과 실패 기록

코어11개·데스크톱4개·Python4개 테스트와 별도51함수 출구 호스트를 추가했습니다. Splat 직후 Exiting에서 타이머 복구41→0,정지 Exiting의 타이머 만료 후 복원 오류,기존 Digger 배치 구출0→2를 실제 실패 테스트로 확인해 고쳤습니다. 배치 테스트 확장의 소유권 컴파일 오류는 수정 후 집계 assertion 실패를 다시 관측했습니다. 최초 HUD 테스트의 cfg 배치 오류도 수정했습니다.

합성9사례18재생7578상태/1770캡처는 실제 기준 실행과 일치합니다. 원본 Fun01의고정 입력60을 렌더1/7·실시간으로 대조하고 실제 D키/마우스 입력61도 별도로 대조했습니다.4재생2804상태/345캡처에서10마리 모두 구출되었습니다. 원본 검증1은 생성 전 ID 인덱스 접근의 검증기 오류로 제외하고 검증2를 최종 증거로 사용합니다.

새 DOS1은 child-window 검색 지연에 따른 커서 조정 실패,2는 입력에 성공했으나 출구 전 관측 종료로 제외합니다. 전용 display에서 기존 #31 키보드 제어를 사용하고 관측 시간을 늘린3/4는 독립 실행 모두 프레임0~7·제거·구출1~3을 관측했습니다.9개 전체 게임 화면의 일치도 각각 확인했습니다. 원본 EXE/50파일은 수정하지 않았고 별도 생성 런타임 seed만 사용했습니다. 전용 Xvfb/자식 프로세스는 종료했습니다.
