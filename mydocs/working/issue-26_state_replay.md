# G05-04 상태 추적·재생 진행 기록

작업 이슈: [GitHub #26](https://github.com/edwardkim/ohmylemmings/issues/26). 상위: [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 범위와 순서

번호·URL·OPEN을 확인했습니다. #5 비교 계약과 #23~#25 코어를 기준으로 구조화 추적·입력 재생·최초 차이 진단을 구현합니다. 고정 Lemmix 원문 함수를 추출해 실행하는 하네스를 준비하고 F00의 지원 필드를 대조합니다. 실제 DOS 실행·미지원 직업/객체/출구는 검증 범위에 포함하지 않습니다.

## 현재 상태

구조화 추적·입력 재생·최초 차이 진단과 실제 고정 Pascal 함수 하네스를 구현했습니다. 합성 42사례 및 원본 다섯 시나리오가 지원 필드에서 일치합니다. 순수 no_std 코어는 유지하고 파일/JSON/해시는 개발 어댑터에서 처리합니다. 원본과 추출 소스/실행 파일은 assets/local/에 보관합니다.

## 다음 행동

합성 추적·변조/누락·입력 순서 오류의 Red 테스트, 재생 어댑터 구현, 참조 하네스 대조, 공통 검사와 게시 CI를 순서대로 진행합니다.
