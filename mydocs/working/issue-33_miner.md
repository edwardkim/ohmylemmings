# G07-03 Miner 진행 기록

이슈: [#33](https://github.com/edwardkim/ohmylemmings/issues/33), 상위 [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 범위와 현재 상태

번호·URL·OPEN을 확인했습니다. Miner 할당·수량·방향별 마스크·대각 이동·강철/일방통행/낙하/경계와 Digger/Basher 교체를 구현하고 네이티브 선택·입력·스프라이트·재생에 연결합니다. 나머지 직업·완주·전체 DOS 인증은 후속 범위입니다.

## 다음 행동

기준 함수를 읽고 행동 테스트를 먼저 작성합니다. 실제 기준 함수 실행·합성 오프라인 회귀·원본 읽기 전용 관측을 분리해 검증합니다. 원본 파생물·외부 소스/바이너리·실행 산출물은 ignored assets/local에 둡니다.

## 진행

- 코어 새9개·768조합과 네이티브 새2개를 Red→Green으로 검증했습니다. Miner 진입 시 y+1도 별도 실패 테스트로 고정했습니다.
- 기존 기준 호스트의 미사용 Mining 플래그가 Floating과 겹쳤습니다. 새 호스트에서 별도 플래그로 수정하고 원문24개 함수 본문은 유지했습니다. 초기 기준 실행1은 최종 증거에서 제외합니다.
- 실제 기준 함수의 합성6사례/12재생/2652상태/146캡처·전체 삭제가 일치했습니다. Fun04 원본 수량1개·네이티브 입력80을 확인하고 실제 입력과 DOS 읽기 전용 관측/전체 장면을 대조합니다.

- 실제 클릭 관측이 쓰기 중인 JSONL 끝을 읽은 문제를 완성 줄 단위로 수정하고 실패/성공 테스트를 추가했습니다. 원본 회귀 Digger1023상태/135캡처·Basher1023상태/42캡처는 기존 서명을 유지합니다.
- 준비 DOS3은 DOS2와 전용 화면이 겹쳐 실패했습니다. 최종 실행은 순서대로 수행하며 준비/실패 실행은 최종 횟수에서 제외합니다. 불완전 메모리는 살아 있는 프로세스에서 거부하고 종료 후 EOF만 별도로 기록하는 테스트도 추가했습니다.

## 로컬 검증 완료

- 최종 DOS4/5의1228샘플·4676게임 프레임/220·260·340 전체 장면×2회가 일치했습니다. 원본 Miner4실행/1244상태/53캡처·실제 M키/클릭, 원본 Digger/Basher 각3재생과 F00도 통과했습니다.
- Rust342/문서27·최종 Python47·기존/추가 회귀·SDL·WASM, 원본50개/소스46개·각 실행 복사본50개,101소스/1024산출물 해시를 확인했습니다. 다음은 구현/문서 게시와 실제 CI·상위 진행·이슈 종료입니다.
