# 전체 구현 계획 수립 진행 기록

## 현재 상태

계획 수립과 [상위 이슈 #1](https://github.com/edwardkim/ohmylemmings/issues/1) 등록을 완료했습니다. G00의 원작 확보(#2)·소스 고정(#3)·비교 계약(#5), [G01-01 / #6](issue-6_rust_workspace.md)의 개발 골격과 [G01-02 / #7](issue-7_continuous_integration.md)의 실제 CI 검증을 마쳤습니다. [G02-01 / #8](issue-8_dat_sections.md) 구간 읽기와 [G02-02 / #9](issue-9_dat_decompression.md) 압축 해제의 검증으로 G02도 완료했습니다. G00·G01·G02는 완료, G03는 [G03-01 / #10](issue-10_level_records.md) 이후 [G03-02 / #11](issue-11_level_catalog.md)도 마쳤습니다. [G03-03 / #12](issue-12_ground_metadata.md)도 합성 테스트·원본 5개 전체 필드 대조·실제 CI를 통과해 완료했습니다. [G03-04 / #13](issue-13_vgagr_images.md)도 합성 테스트·원본 전체 픽셀 대조·실제 CI를 통과해 완료했습니다. [G03-05 / #14](issue-14_vgaspec_backgrounds.md)도 합성 테스트·원본 전체 픽셀 대조·실제 CI를 통과해 완료했습니다. [G03-06 / #15](issue-15_level_terrain.md)도 전체 120개 지형·팔레트 대조·로컬 검사·실제 CI를 통과해 완료했습니다. [G03-07 / #16](issue-16_lemming_sprites.md)도 전체 프레임 대조·로컬 검사·실제 CI를 통과해 완료했습니다. [G03-08 / #17](issue-17_main_ui.md)도 지원 이미지/글리프 전체 대조·로컬 검사·실제 CI를 통과해 완료했습니다. [G03-09 / #18](issue-18_main_masks.md)은 전체 비트 대조·로컬 검사를 마쳐 게시·실제 CI를 확인합니다. G03 전체는 객체 이미지 배치·합성이 남아 진행 중이며 G04는 준비 상태입니다. 나머지 구현 목표는 선행 작업을 기다립니다.

- 원본 호환 범위 확정부터 배포까지 13개 목표로 분할했습니다.
- 목표별 선행 조건, 작은 작업, 완료 증거를 정의했습니다.

- 문서 링크 36개와 공백, 13개 목표의 의존관계를 검사했습니다.
- 이슈 #1에 13개 구현 목표 체크리스트를 등록했습니다.
- 문서를 `main`에 게시하고 원격 파일 17개의 blob 해시가 로컬과 일치함을 확인했습니다.
