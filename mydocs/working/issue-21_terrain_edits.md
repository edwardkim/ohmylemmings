# G04-02 지형 쓰기·셀 변경 진행 기록

작업 이슈: [GitHub #21](https://github.com/edwardkim/ohmylemmings/issues/21). 상위: [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 범위와 순서

번호·URL·OPEN 상태를 확인하고 착수했습니다. 생성 검증·bool 쓰기·대여 수명 계약 → 합성 Red/Green → 작은 마스크 전수 변경·TS 유효 좌표 대조 → 문서·검사·게시·실제 CI 순서로 진행합니다.

원시 가변 바이트는 노출하지 않습니다. 일괄 추가/삭제·클리핑·게임 규칙·리소스 연결은 후속 범위이며 G04 전체는 진행 중입니다.

## 현재 상태

가변 뷰·안전한 bool 쓰기·읽기 전환을 구현하고 전수 대조·공통 검사를 통과했습니다.
