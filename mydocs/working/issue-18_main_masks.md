# G03-09 MAIN.DAT 마스크·카운트다운 진행 기록

작업 이슈: [GitHub #18](https://github.com/edwardkim/ohmylemmings/issues/18). 상위: [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 범위와 순서

번호·URL·OPEN 상태를 먼저 확인했습니다. 고정 소스·원본 분석 → 합성 Red/Green → 무할당 API → 전체 지원 항목 독립 대조 → 문서·검사·게시·실제 CI 순서로 진행합니다.

비트 마스크·글리프 리소스만 해석합니다. 지형 변경 적용·충돌·타이밍·화면·객체 합성은 후속 범위입니다.

## 현재 상태

마스크 구간·비트/글리프 API와 호스트 예제·검증 매니페스트를 구현하고 로컬 검증·실제 CI·원격 게시 확인을 마쳤습니다. [기술 계약·재현 명령](../tech_insights/issue-18_main_masks.md)과 [결과 보고서](../reports/issue-18_main_masks.md)에 근거를 기록했습니다. 최종 문서 게시·CI와 #18 종료는 GitHub 이슈 기록에서 추적합니다.

## 수행과 근거

- 원본 50개·기존 소스 46개의 해시와 새 고정 소스 4개의 크기·git blob·SHA-256을 확인했습니다.
- 새 합성 14개 실패·기존 리소스 151개 통과의 Red 이후 Green 165개를 확인했습니다.
- `make check`: Rust 단위 167개·문서 예제 13개·Python 8개, 포맷·Clippy·빌드·WASM 성공.
- 원본 MAIN을 독립 Python으로 직접 해제해 기존 7개 구간의 모든 바이트·해시를 유지했습니다.
- 6개 묶음·23프레임·3104비트(선택 923개)가 Rust·Python·실제 TS 원시 데이터와 일치합니다. Lemmix의 5→1 부분 목록도 대조했습니다.
- TS의 -128/0 원문과 반대 극성 at 조회, 숫자 인덱싱·위치 차이, MaskList.length의 실제 Node 오류를 기록했습니다. API는 비트 1을 선택으로 반환하며 전체 9→0 글리프를 지원합니다.
- CLI 오류 10개에서 원본·기존 출력·미리보기 보존을 확인했습니다. 전체 프레임 미리보기와 문서 재현 명령도 검증했습니다.
- Markdown 69개·로컬 링크 466개·앵커 78개·이슈 문서명 57개·#18 일지·고정 입력 4개·추가 소스 7개·기존 로컬 의존 하나를 확인했습니다. 앞 단계 매니페스트는 변경하지 않았습니다.
