1. #17 UI 파서, #27 입력, #30 화면, #54 세션 교체와 고정 Lemmix/TS 패널 참조를 읽고 버튼/반복/미니맵 계약을 확정합니다.
2. 합성 테스트로 버튼 경계·선택·명령·미니맵 변환·지형 변경·세션 초기화의 실패를 확인한 뒤 구현합니다.
3. 원본 패널/숫자/글리프 로딩 및 SDL 렌더·입력을 연결합니다. 렌더 주기와 분리된 논리 입력 로그를 유지합니다.
4. 오프라인 회귀·실제 SDL 입력/화면·DOS 비교를 기록하고 자체 검토, 문서 동기화, 한글 PR로 게시합니다.
