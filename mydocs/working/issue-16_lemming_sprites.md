# G03-07 MAIN.DAT 레밍 스프라이트 진행 기록

작업 이슈: [GitHub #16](https://github.com/edwardkim/ohmylemmings/issues/16). 상위: [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 범위와 순서

번호·URL·OPEN 상태를 먼저 확인했습니다. 고정 소스·원본 레이아웃 분석 → 합성 Red/Green → 무할당 API → 전체 프레임 독립 대조 → 문서·검사·게시·실제 CI 순서로 진행합니다.

레밍 스프라이트만 해석합니다. MAIN.DAT UI·폰트·마스크, 재생·물리 규칙과 객체 합성은 후속 범위입니다.

## 현재 상태

무할당 MAIN 구간 0·애니메이션·방향·프레임 API와 호스트 예제·검증 매니페스트를 구현하고 로컬 검증을 마쳤습니다. [기술 계약·재현 명령](../tech_insights/issue-16_lemming_sprites.md)과 [결과 보고서](../reports/issue-16_lemming_sprites.md)를 작성했습니다. 게시·실제 CI·원격 파일 대조 후 이슈를 완료합니다.

## 수행과 근거

- 고정 Lemmix 메타데이터와 TS를 분석하고 원본 50개·기존 소스 46개를 해시 검증했습니다. 추가 소스 5개는 고정 커밋의 크기·git blob·SHA-256을 확인했습니다.
- 합성 Red 14개 실패·기존 리소스 121개 통과 후 Green 135개를 확인했습니다.
- `make check`: Rust 단위 137개·문서 예제 11개·Python 8개, 포맷·Clippy·빌드·WASM 성공.
- 원본 MAIN의 모든 구간을 독립 Python으로 해제해 기존 G02의 7개 해시·전체 바이트가 일치함을 확인했습니다.
- 28개 애니메이션·337프레임·63488개 인덱스/투명 픽셀이 Rust·독립 Python·실제 고정 TS와 일치합니다. 진단 팔레트로 실제 TS의 RGB/알파/점유도 대조했습니다.
- 기준점 4개·방향 조회 2개의 차이를 기록하고 Lemmix 규칙을 적용했습니다. API는 팔레트·재생·물리와 분리됩니다.
- CLI 오류 10개에서 경로 문맥·기존 출력/원본 보존을 확인하고 미리보기를 검토했습니다. 문서 재현 명령도 그대로 실행해 통과했습니다.
- Markdown 63개·로컬 링크 416개·앵커 70개·이슈 문서명 51개·#16 일지·추가 소스 9개·고정 입력 3개·기존 로컬 의존 하나를 확인했습니다. 앞 단계 매니페스트는 변경하지 않았습니다.

구현·문서 게시 → 실제 CI → 원격 파일 대조 → 최종 문서 게시·CI → 상위 #1 갱신·#16 종료 순서로 마칩니다. G03 전체는 UI·폰트·마스크와 객체 합성이 남아 진행 중입니다. 다음은 새 이슈의 G03-08 MAIN.DAT UI·폰트 해석이며 G04-01도 준비 상태입니다.
