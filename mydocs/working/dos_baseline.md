## 확인한 내용

- Lemmix의 고정 커밋에서 원작 데이터 ZIP을 확보했습니다. DAT 파일 26개가 들어 있습니다.
- Lemmings.ts의 원작 파일 크기 목록과 대조했습니다.
- 별도로 확보한 DOS 영어 데모는 MAIN.DAT와 ADLIB.DAT 크기가 원작 목록과 다릅니다.
- 공개된 원작 데이터 사본에서 보충 파일을 확보했고 50개 파일의 출처·해시를 기록했습니다.
- `reference_assets.py`의 오류 경로 테스트 6개와 로컬 체크섬 검증을 통과했습니다.
- 별도 폴더에 50개 파일을 다시 확보하고 동일한 크기·SHA-256을 확인했습니다.
