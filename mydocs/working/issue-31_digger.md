# G07-01 Digger 진행 기록

이슈: [#31](https://github.com/edwardkim/ohmylemmings/issues/31), 상위 [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 범위와 현재 상태

이슈 번호·URL·OPEN 상태를 확인한 뒤 착수했습니다. Digger 할당/수량·상태/지형 삭제·강철/중단/경계와 네이티브 입력·표시·재생을 연결합니다. 고정 레퍼런스와 원본 관측으로 차이를 식별하며 다른 직업·완주/승패·전체 DOS 인증은 후속 범위입니다.

## 다음 행동

기준 함수·기존 motion/terrain/session/trace 경계를 읽고 행동 테스트를 먼저 작성합니다. 원본 50개·메모리·실행 파일은 변경하지 않습니다. 검증 결과와 남은 한계는 보고서에 기록합니다.

## 진행

- 코어 Digger 할당·초기 세 줄·8틱 주기·공백/강철 전환·클리핑/오류 보존·ID 순 지형 관측의 8개 테스트가 Red→Green입니다.
- 고정 Pascal 원문 18개 함수 하네스를 실제 실행했습니다. 합성 6사례·두 렌더 주기의 4092상태와 모든 삭제 인덱스가 일치했습니다. 기준 어댑터를 최종 고정한 뒤 기록 golden과 전체 검사를 갱신합니다.
- 네이티브 클릭/정수 ID 재생·원본 Digger 스프라이트·가변 지형/객체 합성·수량/추가 지형 기록을 연결했습니다. 기존 g05-basic 기록은 유지합니다.
- 원본 DOS 키보드/읽기 전용 필드로 첫 Walking 직후 할당과 native 경계 60의 대응을 계측 중입니다. 다른 직업/커서 중복 선택·객체/출구·완주 인증은 후속 범위입니다.

## 검증 완료·게시 준비

- 최종 기준 실행의 합성6사례/12재생/4092상태/534캡처, 원본 네이티브4실행/1204상태/160캡처·전체 삭제 목록이 일치합니다. 실제 클릭의 경계61 입력도 기준 함수로 재생했습니다.
- DOS 최종 두 실행6/7에서 counter61 Walking→62 Digging·수량10→9를 읽기 전용으로 관측했습니다. 1170샘플/게임 영상4435프레임과 100/170/340 전체 장면×2회의 0픽셀 차이를 확인했습니다. 초기 준비 실험은 횟수에서 제외합니다.
- 52개 소스와 561개 산출물 및 원본/참조 해시를 [증거](../../assets/manifests/digger.json)에 고정했습니다. 전체 검사320/27/37·기존 모델/기준/SDL·WASM을 통과했습니다. 다음은 문서/저장소 게시·실제 CI·상위 진행 갱신·#31 종료입니다.
