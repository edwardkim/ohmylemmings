## 변경 내용

MAIN.DAT 구간 2·3·4·6의 UI·폰트 리소스를 해석했습니다. 메뉴·로고·버튼·아이콘·좌우 각 16프레임 스크롤·평가판·메뉴 글꼴·스킬 패널·패널 글꼴·좌우 숫자, 총 19개 묶음·200개 이미지/글리프를 제공합니다.

기존 `MainDatFile`에 선택 구간의 선언/출력 길이 검사와 호출자 버퍼 해제를 연결했습니다. `MainUiRecord`·`UiImages`·`UiImage`는 원래 인덱스·순서·stride와 묶음별 투명도 정책을 보존하고 잘못된 태그·글자·인덱스·좌표·출력 길이를 검사합니다. 메뉴 ASCII 94개, 패널 38개와 ASCII 소문자 연결을 지원하며 생성된 공백이나 UI 상태를 추가하지 않습니다.

팔레트 역할과 인덱스·점유를 분리했습니다. RGB가 검정인 색상 0도 배경·패널·패널 글꼴에서는 불투명합니다. 선언/출력 길이 오류는 출력을 보존하고 압축 명령 오류는 부분 출력 가능성을 명시합니다. 미해석 범위를 포함하는 모든 원문 바이트를 보존하며 외부 패키지·라이브러리 할당/I/O 없이 `no_std`와 기존 로컬 의존 하나를 유지했습니다.

호스트 `inspect_ui` 예제, [고정 이미지·구간 해시 매니페스트](../../assets/manifests/main_ui.json), 로컬 미리보기와 재현 명령을 추가했습니다. 원본·생성 PNG·바이너리·JSONL은 Git 추적에서 제외합니다.

패널/글꼴의 색상 0·로고 632폭·플레인/행/프레임 경계·좌우 숫자 교차 stride·전체 문자 범위·큰 인덱스·출력만 빌리는 수명을 합성 입력으로 확인했습니다. TS에서 제공하지 않는 메뉴 글꼴·평가판·스크롤 후속 프레임은 Lemmix에 근거합니다. 미리보기의 패널 팔레트는 진단용이며 실제 화면 색상 인증은 아닙니다.

## 게시 상태와 다음 범위

로컬 검증을 마쳤으며 문서 재현·추적 검사와 실제 push CI·원격 파일 대조를 확인해 완료합니다.

이번 완료 범위는 식별된 19개 UI 묶음입니다. 미사용 범위·전체 MAIN 구간 1·5의 의미를 인증하지 않습니다. 화면 조립·입력·문자열 배치·HUD·실제 DOS 실행은 후속 범위입니다. G03 전체는 변형 마스크·카운트다운과 객체 합성이 남아 진행 중이며 다음은 별도 이슈의 G03-09 MAIN.DAT 마스크·카운트다운 해석입니다. G04-01도 준비 상태입니다.
