## 변경 내용

`compose_terrain`은 LVL·GROUND/VGAGR 또는 VGASPEC을 연결해 1584×160 초기 지형을 호출자 버퍼에 합성합니다. 파일 순서·마스크·수직 반전·클리핑과 Lemmix의 no-overwrite 우선순위를 구현했습니다. 특수 배경은 (304,0)에 놓고 일반 배치를 건너뜁니다. 인덱스·점유와 팔레트를 분리하므로 검정도 불투명 지형으로 유지합니다.

선택자·정확한 출력 길이·화면 밖을 포함한 전체 활성 지형 ID를 먼저 검증해 모든 오류에서 출력을 보존합니다. 결과는 출력 버퍼만 빌리고 팔레트를 복사합니다. `no_std`·무할당·I/O 없는 라이브러리와 기존 리소스→코어 의존 하나를 유지하며 외부 패키지는 추가하지 않았습니다.

호스트 `inspect_terrain` 예제는 120개 맵과 JSONL 메타데이터를 출력하고 기존 파일의 덮어쓰기를 거부합니다. [지형 검증 매니페스트](../../assets/manifests/level_terrain.json)에 독립 비교 후 고정한 80개 기본 맵의 인덱스·RGBA 해시·팔레트·점유 수와 추가 소스 식별값을 기록했습니다.

## 범위와 게시 상태

초기 지형과 팔레트 재구성 범위의 로컬 검증을 마쳤습니다. 구현·문서를 게시한 뒤 실제 push CI와 원격 파일 해시를 확인하고 이 문서에 기록합니다.

이 결과는 객체 합성·강철/충돌·지형 변경·게임 화면·실제 DOS 실행 호환성을 판정하지 않습니다. G03 전체는 MAIN.DAT 레밍 스프라이트·UI와 객체 배치 합성이 남아 진행 중입니다. 다음은 별도 이슈의 G03-07 MAIN.DAT 레밍 스프라이트 해석이며 G04-01 픽셀 지형 읽기·경계 검증도 준비 상태입니다.
