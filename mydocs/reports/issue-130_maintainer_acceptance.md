# #130 Windows 11·웹브라우저 메인테이너 인수

이슈: https://github.com/edwardkim/ohmylemmings/issues/130

2026-10-22 메인테이너가 직접 테스트한 결과를 다음과 같이 보고했다.

> 130번 이슈는 메인테이너가 직접 윈도우11과 웹브라우저에서 테스트를 진행했고 성공 판정입니다.

| 환경 | 결과·지원 상태 | 근거 |
|---|---|---|
| Windows 11 | 성공 | 메인테이너 직접 테스트·인수 판정 |
| 웹브라우저 | 성공 | 메인테이너 직접 테스트·인수 판정 |
| Windows 10 | 지원하지 않음 | 2026-10-22 메인테이너의 지원 제외 결정 |

이 성공 판정을 #130의 완료 근거로 수용한다. 초기 Windows 10/11 계획에서 이번에 보고된 인수 범위는 Windows 11·웹브라우저이다. 개별 화면·입력·청취 항목의 상세 기록, OS build·브라우저 종류/버전·배율·장치 사양, 실제 검사한 버전/ZIP SHA256은 제공되지 않았다. 보고에 없는 세부 항목을 개별 통과로 표시하지 않는다.

## Windows 지원 범위 확정 / 2026-10-22

메인테이너가 다음과 같이 결정했다.

> 윈도우 10 은 지원 안 하는 걸로 결정합니다.

Windows 지원 대상은 **Windows 11 x64**로 정하고 **Windows 10은 지원하지 않는다**. 앞선 인수 기록의 Windows 10 미검증 상태는 이 지원 제외 결정으로 정리한다. 초기 Windows 10/11 계획 중 Windows 10 수동 검증은 완료 조건과 후속 작업에서 제외한다. #130의 완료 상태와 Windows 11·웹브라우저 성공 판정은 유지한다.

README·데스크톱 실행 안내·배포/릴리즈 정책·상위 추적에 지원 범위를 반영한다. 기존 v0.1.0 태그·배포 파일·버전별 릴리즈 노트는 당시 기록으로 보존한다. 이후 릴리즈 안내와 Windows 패키지 실행 안내에도 같은 지원 범위를 적용한다.

## 인수 기록 반영·검증

초기 계획의 v0.1.0 Windows ZIP SHA256 `44fef8d9c20b4396a37b910353899b80307c5e6c5472f473d5d859392fbde138`은 기준 자료이다. 이번 수동 검사의 패키지 해시 확인 결과로 소급하지 않는다. 기존 자동 실행/PCM 증거는 각 #118/#122/#126 보고서에 보존하며, 이번 완료 근거는 메인테이너의 직접 테스트 보고이다.

[PR #134](https://github.com/edwardkim/ohmylemmings/pull/134)에서 [진행 기록](../working/issue-130_windows_manual_validation.md)·README·상위 계획·#115 후속 상태와 [작업일지](../orders/20261022.md)를 동기화했다. 당시 변경 문서12개의 상대 파일 링크483개·git diff --check PASS. self-review에서 직접 보고된 두 환경의 성공과 당시 Windows 10/세부 항목의 미검증을 대조했다. merge51e8efb로 실제 병합하고 #130을 완료 처리했다. 지원 범위 확정 후속의 검증·병합 결과도 GitHub 이슈에 연결한다. 문서 전용 변경으로 전체 플랫폼 빌드·게임 재실행은 반복하지 않는다.

지원 범위 확정 후속에서는 변경 Markdown15개의 상대 파일 링크519개·git diff --check를 통과했다. self-review에서 Windows 10 지원 제외가 현재 안내·완료 조건에 일치하는지, 초기 계획/일지와 기존 버전별 노트가 당시 기록으로 보존되는지 확인했다.

더 좋은 호스트의 성능·구간 메모리 검증은 [#113](https://github.com/edwardkim/ohmylemmings/issues/113)에 남아 있으며 #1/G11/G12 전체 완료 판정은 계속 보류한다. 이번 작업은 테스트 결과 기록으로 게임 코드나 배포 파일을 변경하지 않는다.
