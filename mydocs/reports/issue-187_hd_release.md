## 변경과 인수 범위

Linux x86_64·Windows11 x64·macOS universal2·Web의 새 패키지는 전체 `hd-assets/`와 `HD-ASSETS.json`, `HD-PRESENTATION`을 포함하고 HD로 시작한다. Native는 실행 파일 옆 또는 Mac `Contents/Resources`를 기준으로 찾으므로 다른 작업 디렉터리·공백/한글 설치 경로에서도 실행된다. `--original`로 원본을 시작하고 F8/Web 선택기로 전환한다. 개발 체크아웃·합성 검사·기존 성능 실행의 기본 모드는 유지한다. Web은 패키지 표식을 읽어 첫 HD 자산 로딩이 끝난 뒤 게임을 표시한다.

899논리 키(캐릭터337·객체540·재질5·아이콘13·특수4), 95개 Noto Sans AA 글꼴과 현재 상태/기술/미니맵·Pause/Nuke·결과 UI가 대상이다. 원본273지형 조각은5개 새 재질과 원본 마스크를 사용한다. DOS의 미사용 메뉴 이미지200개를 새로 구현하거나 한국어 글꼴을 추가하는 범위는 아니다. 초기 #138 원본 목록의 미착수 표기를 현재 제품 대응과 구분해 정리했고, 지난 단계의 검증 수치는 과거 기록으로 보존한다.

카탈로그50atlas+index, 총204,704,712바이트와 SHA256 `97704c7cfb4bdb9025cb6a067e37f7d3b575147e3e3b3e184cd9eceec2303a8e`는 #184와 동일하다.25선택 조합의 최대124,698,404바이트는128MiB/32page 한도 안이다. 카탈로그 캐시는 매 호출 PNG/출처 pin을 확인하며, 정상 캐시에서는 PNG 디코딩을 반복하지 않는다. 모든 패키지가 동일한 바이트·출처·글꼴 OFL/제3자 고지·재빌드 소스를 제공한다. 누락/손상된 새 HD 패키지는 기본 시작을 중단하며 원본 명시 실행은 사용할 수 있다. 기존 공개 v0.1.0의 검증도 유지한다.

## 배포·잔여 사항

현재 공개 v0.1.0/태그/Pages는 교체하지 않는다. 이 단계의 같은0.1.0 이름은 CI/로컬 개발 후보 아카이브이며 공개 릴리즈는 새 버전·태그 정책을 거친다. Mac은 ad-hoc/미공증이고 Windows 지원은11만이다. hosted Windows CI 환경은 Server2022이며 실제 Windows11의 이번 HD 패키지 수동 인수를 수행했다고 주장하지 않는다.
