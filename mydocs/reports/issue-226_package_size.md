# 배포 용량 최적화 결과

담당 [#226](https://github.com/edwardkim/ohmylemmings/issues/226). 선행 [용량 조사](issue-224_web_size.md), [계획](../plans/issue-226_package_size.md).

## 적용 범위

정식 릴리즈의 네 실행 패키지에서 중복 대응 소스를 분리하고, 공통 소스 다운로드 하나를 버전 URL·크기·SHA-256으로 연결했다. Pages는 그 소스를 검증하지만 사이트에 중복 배치하지 않는다. CI 개발용 패키지는 자체 실행 검증을 위해 선별한 소스를 계속 내장한다.

소스 묶음에서는 현재 HD manifest가 직접 참조하는 atlas·provenance·catalog extension만 남긴다. v0.3.2 대비 과거 미술/미리보기 74개(31,488,746바이트), 측정 JSONL 4개(3,665,384바이트), 이전 문서/이미지 366개(4,314,090바이트), 합계444개·39,468,220바이트를 배포 대상에서 제외했다. 저장소 역사 자료는 보존한다. 현재 버전 릴리즈 노트, 실제 빌드 입력, 소스 코드, 테스트, 라이선스/재링크 안내, 폰트·아이콘은 보존한다. 축소 소스는 빌드용이며 과거 감사 증거 전체를 포함하지 않는다.

Web 생성 디렉터리에서 더 이상 manifest가 참조하지 않는 content-addressed HD 압축 파일도 제거한다. 임의 사용자 파일과 심볼릭 링크는 삭제하지 않는다. 실제 사용 중인 원본 모드 데이터와 HD53페이지를 유지한다.

## 검증

- Python339개 통과. 네 플랫폼 패키지 런타임 내용/권한 유지, 별도 소스 누락/변조·잘못된 URL 거부, Pages 소스 제외, 오래된 HD 생성물 정리를 검사했다.
- 축소 대응 소스만 추출한 환경에서 WASM 및 Native release 빌드 성공. HD 재생성56파일97,004,652바이트가 공개v0.3.2와 동일했다.
- 실제 소스 분리 Web 패키지 브라우저 스모크 성공: 원본120레벨 로딩, WebAudio nonzero 출력, 재시작/이어하기, HD기본값, Fun01 승리, 다운로드 진행/재시도/백그라운드 및 누락파일 오류 처리. 이는 FPS 성능 인수와 별개다.
- PR#227의 CI40140861375는7개 검사 통과. 이후 실제 prepare-only40142262227에서 플랫폼별 소스 파일 내용은 같지만 압축 컨테이너 바이트가 달라 중단됐다. 공개 게시/Pages는 실행되지 않았다.
- PR#228은 모든 플랫폼 소스 파일 내용을 먼저 비교하고, 게시 호스트의 단일 소스 압축 파일로 정규화하도록 보정했다. 압축 표현이 다른 동일 소스는 허용하고, 코드가 달라진 소스는 거부하는 회귀 테스트를 추가했다.

[최종 CI40142786823](https://github.com/edwardkim/ohmylemmings/actions/runs/40142786823) 7개 검사 모두 통과. 입력 head는 `5d945a5a25abc2449cc19b850542f05dbba2047a`, 실제 PR checkout은 `5498335`이며 병합 main `43a03ea2e0932801db076d003d4d348882b6cb6d`와 같은 tree `a73c1bc86f2dd9f786db811efc816e08ac9cd770`이다.

[최종 prepare-only40143689287](https://github.com/edwardkim/ohmylemmings/actions/runs/40143689287) 성공. 이 main에서 실제 네 CI 패키지·원본120레벨 설치 증거·동일 tree 소스836파일을 대조한 뒤, 별도 소스 방식의 네 패키지와 총12개 게시 자산을 검증했다. `release-preflight` artifact의 RELEASE-MANIFEST/SHA256SUMS가 위 수치의 근거다. Pages 작업은 의도대로 skipped이며 실제 publish 단계는 실행하지 않았다. v0.3.2 이름은 현행 workspace 버전을 이용한 사전 검증 전용으로, 이 후보를 기존 공개 v0.3.2 대신 제공하면 안 된다.

개인 측정/실행 증거는 ignored `assets/local/issue-226-review/`에 둔다. 정확한 공개 검증 근거는 위 GitHub CI/사전 검증 링크와 그 artifact다.

## 게시 상태

구현/검증의 완료와 새 버전 배포는 구분한다. 공개 v0.3.2 및 Pages는 그대로이며 새 태그 생성이나 릴리즈 파일 덮어쓰기는 하지 않았다. 새 버전 릴리즈 시 이 배포 방식이 적용된다. #113 성능 인수 NOT READY와 원본 자산의 권리 경계는 변경하지 않았다.
