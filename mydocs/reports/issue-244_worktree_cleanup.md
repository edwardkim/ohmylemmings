# 완료 워크트리 정리와 디스크 공간 확보

담당 [#244](https://github.com/edwardkim/ohmylemmings/issues/244). 2026-10-25 메인테이너의 시스템 디스크 확보 요청에 따라 정리했다.

## 결과

| 항목 | 정리 전 | 정리 후 |
|---|---:|---:|
| 등록 워크트리 | 64개 | 2개 |
| 파일시스템 사용률(df) | 91% | 72% |
| 가용 공간 | 10.52 GiB | 30.58 GiB |

실제 확보 공간은 **21,532,528,640바이트(20.05 GiB)**다. Btrfs 압축·공유 extent와 보존한 산출물이 있으므로 워크트리별du 합계나 빌드 디렉터리33.88GiB와 실제 회수량은 다르다. 위 수치는 같은 파일시스템의 가용 공간을 정리 전후 비교한 값이다.

## 제거 기준과 보존

모든 워크트리의 HEAD/브랜치·main 병합 여부·추적/미추적 변경·사용 중 프로세스를 확인했다. 62개는 main에 병합됐고 변경 사항과 사용 중인 프로세스가 없어 제거했다. 기본 작업 폴더와 미병합 `ohmylemmings-windows-assessment`는 유지했다. 후자는 약47MiB이며 이번에 소스·자료를 삭제하지 않았다.

삭제 전 각 워크트리의 `assets/local/`, 재현에 사용할 실행 파일·WASM·라이브러리 산출물 등을 아래 중앙 경로로 같은 파일시스템에서 이동했다. 추가 복사나 대규모 압축 파일 생성 없이 디스크 여유를 유지했다.

```text
assets/local/worktree-archive/issue-244/<이전 워크트리 이름>/assets/local/
assets/local/worktree-archive/issue-244/<이전 워크트리 이름>/target/...
```

보존 항목52,770개에 대해 regular file의 device/inode·크기·mtime, 기존 유효 symlink의 대상 inode를 확인했다. 기록은 원시 데이터의 내용 변경 없이 이동했음을 검증한다. 재생성 가능한 Cargo deps/build/incremental 캐시, Python 캐시와 병합 완료된 소스 checkout 복사본을 정리했다. Git 브랜치·태그·커밋 이력은 모두 유지했다.

미리보기의 기존 경로를 유지하기 위해 기본 작업 폴더의 `preview-113`, `preview-215`, `preview-216` 링크를 보관 경로로 바꿨다. 보관 자료 내부 symlink도 원래 가리키던 대상에 연결되도록 정규화했다. 과거 로그에 들어 있는 이전 절대 경로 문자열 자체는 증거 보존을 위해 수정하지 않았다. 재현 시 중앙 보관 경로와 아래 이동 목록을 사용해야 한다.

## 검증

- 이동 전후 및 워크트리 제거 후 보존 항목52,770개를 확인했다. 삭제 전에 자료 검증을 완료하고, 삭제 뒤에도 같은 inode/파일 크기/mtime 및 유효 링크를 재확인했다.
- 모든 기존 브랜치와 태그의 ref/commit이 정리 전후 같음을 확인했다. 정리 기록 PR에 의한 이후main 이동은 별도다.
- 기존 HTTP8080 서버 PID30164를 유지했다. 루트 페이지와 세 미리보기의 HTTP200·본문 크기/SHA가 전후 동일했고, 세 미리보기의 app.js/WASM 요청도 정상이다.
- 기본 Native 실행 파일의 실제 OpenGL 시작·presentation_base_fps40·1틱 smoke를 통과했다. 기본 작업 폴더의 소스 상태가 깨끗함을 확인했다.
- 남은 미병합 워크트리의 symlink 이상은 없고, git worktree prune의 오래된 등록 정보도 없다. 기존 사용자 앱/브라우저·음악·시스템 설정을 변경하거나 프로세스를 종료하지 않았다.

정리 중 임시 assets/local 연결이 Git에 미추적 항목으로 보여 삭제 전 검사가 한 번 멈췄다. 이때 자료 이동·검증만 끝난 상태였고 워크트리는 삭제되지 않았다. 알려진 임시 링크만 해제하고 변경 없음 검사를 다시 수행한 뒤 삭제를 진행했다.

## 상세 기록

개인 인벤토리와 경로 이동 목록은 ignored `assets/local/issue-244-cleanup/`에 있다: `before.json`, `plan.json`, `preserved-files.jsonl`, `journal.jsonl`, `after.json`, 미리보기 검사와 Native smoke 로그. 목록에는 보존된 새 절대 경로와 이전 워크트리의 HEAD/브랜치가 기록돼 있다. 기본 작업 폴더를 포함한 등록 워크트리2개가 남았으며, 중앙 증거 보관 폴더는 Git 워크트리가 아니다.

게임 코드·릴리즈·공개 Pages에는 변경이 없다. 새 워크트리를 만들지 않고 기본 작업 폴더에서 기록용 브랜치를 사용했다.
