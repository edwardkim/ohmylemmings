# G09-01 공유 게임 세션 분리 결과

이슈: [#62](https://github.com/edwardkim/ohmylemmings/issues/62) · [계약·재현·후속 범위](../tech_insights/issue-62_shared_session.md) · [출처·증거](../../assets/manifests/shared_session.json)

Session/Pacing을 `lemmings-session`으로 옮기고 네이티브가 같은 구현을 재노출해 사용하도록 연결했습니다. Session이 호출하던 포인터 기술/ID 명령 변환도 공유 경계로 옮겼습니다. 새 크레이트의 의존성은 core 하나이며 SDL·resources·파일/시스템 시계·브라우저 호출은 없습니다. core/resources의 no_std와 외부 패키지 목록을 유지합니다.

기존 세션24개·재생 시계5개의 테스트를 공유 크레이트로 옮겼습니다. 테스트 전용 최소 지형/객체 fixture를 넣어 SDL/리소스 없이 같은 행동을 검사합니다. 공개 API 실패 테스트부터 구현하여 경과 시간과 명시 tick 분리·호출 빚 보존, 여덟 기술의 포인터/안정 ID 경로 일치, 종료 후 입력 거부·고정 상태와 새 세션/시계 초기화를 추가했습니다. 공개 API3개와 문서 예제1개도 통과했습니다.

추출 전6실행1912상태/413캡처와 추출 후 렌더1/7의12실행3824상태/826캡처를 확인했습니다. 모든 정규화 상태·순서 있는 지형/객체 이력, 초기/최종 bin과 모든 논리 RGB가 같습니다. Session 전체는 명령 함수 위치와 테스트 fixture 경로만 바뀌었고 Pacing·명령 변환 본문은 바이트 단위로 같습니다.

WASM 전용 새 target 디렉터리에서 공유 크레이트와 core만 독립 컴파일했습니다. 기존 workspace 라이브러리 WASM 빌드에도 공유 세션이 포함됩니다. 이는 rlib 컴파일 검증이며 JS 바인딩이나 실제 브라우저 실행을 완료로 표시하지 않습니다.

추출 전후 합성/원본 상태·픽셀 대조와 전체 로컬 회귀 결과를 확인하고 자체 검토·문서/증거를 동기화합니다. 정확한 게시 head의 push/PR CI 및 병합 main CI·실제 전체 로그·트리/모드/blob·이슈 종료 결과는 [#62](https://github.com/edwardkim/ohmylemmings/issues/62)에 기록합니다.

G08의 규칙·입력·화면 동작은 같은 회귀로 확인합니다. G09는 진행 중이며 다음 G09-02는 자산 바이트 공급과 순수 장면/패널 표현 분리입니다. 원본 파생물은 ignored 경로에만 보관하며 이번 변경은 화면 변경이 없습니다.

자체 검토에서 포인터/안정 ID 비교가 같은 변환 함수의 오류를 공유하지 않도록 직접 명령을 독립 기준으로 지정하고 공개 API3개를 재실행했습니다. 전체 로컬 회귀의 최종 종료 상태와 이 수정 후 CI는 #62에서 구분해 기록합니다.
