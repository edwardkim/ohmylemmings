## 변경 내용과 판단

순수 코어를 바꾸지 않고 std 개발 어댑터로 초기/매 제어 호출의 세션·개체 상태를 기록합니다. JSON 설정의 정렬된 입력을 재생하고, Python 도구가 초기 자료·입력·정적 마스크의 SHA-256과 정규 JSON을 검증합니다. 최초 차이의 제어 경계·필드·앞뒤 상태·전체 마스크를 진단 파일에 남깁니다. 누락/손상은 UNVERIFIED, 지원 필드 일치는 MATCH_SUPPORTED로 구분합니다.

고정 Lemmix의 원문 함수 15개를 추출·컴파일해 실제 실행했습니다. 최소 호스트 자료형/메타데이터와 비게임 스텁을 사용하는 하네스이며 전체 Lemmix/DOS 실행은 아닙니다. 추출 원문과 원본 파생 추적/마스크는 저장소에서 제외하고 해시·합성 golden·재현 도구를 게시합니다.
