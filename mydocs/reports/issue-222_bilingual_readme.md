# 한국어·영어 README와 개발 취지 게시

담당 [#222](https://github.com/edwardkim/ohmylemmings/issues/222). 메인테이너가 검토한 공개 목적·개발 방식·라이선스 경계를 README에 포함하고 한국어/영어로 게시하도록 요청했다.

## 범위와 결과

- README.md를 한국어 기본 문서로 유지하고 README.en.md를 추가했다. 양방향 언어 링크와 같은 순서의 목적·권리 경계·현재 기능·실행/개발·기여 안내를 제공한다.
- REA 미사용은 메인테이너가 밝힌 개발 방식으로 기술한다. Lemmix/Lemmings.ts 참조, 원본 데이터·동작 비교, 기존 OPL 구현 활용을 함께 명시한다. 역공학 없음·완전한 클린룸·권리 확보를 주장하지 않는다.
- MIT의 자체 기여 범위, LGPL/MPL/OFL의 별도 조건, 원본 자산/HD/상표와 사용자 MP3 경계를 설명한다. 현재 v0.3.2와 Pages에 원본 데이터가 포함되며 확인한 자료에 공개 재배포 허락 근거가 없음을 두 언어에 동일하게 표시한다.
- 반복된 과거 진행/후속 예정 문구를 현재 안내에서 정리했다. 세부 이력은 변경 전 커밋 a37aecd의 README와 기존 계획·분석·보고서 링크로 보존한다.
- 최신 v0.3.2 실행 링크·지원 플랫폼·MP3·FPS와 성능 미인수 상태를 유지한다. 기존 공개 릴리즈/Pages/버전 노트/게임 코드는 변경하지 않는다.

## 검토와 검증

문서만 변경한다. 언어별 의미·지원 버전·키·권리 표현을 self-review하고 Markdown 상대 파일 링크의 존재, 언어 전환과 외부 URL 표기, git diff --check를 확인했다(상대 링크59개 및 양방향 언어 링크 통과). 실행 코드 변경이 없어 게임 빌드/플랫폼 CI는 반복하지 않는다. 이 변경은 GitHub main의 README 게시이며 릴리즈 패키지·Pages 자체의 새 배포는 아니다.
