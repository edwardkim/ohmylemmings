## 변경 내용

`MainDatFile`은 MAIN 전체 7개 구간의 헤더·체크섬과 구간 0의 선언 길이를 검사합니다. 호출자 버퍼에 구간 0을 해제하고 `LemmingSprites`로 애니메이션 28개·프레임 337개의 인덱스 픽셀을 제공합니다. 18종 이미지의 방향별 10쌍과 공유 8개, 원본 슬롯·발 기준점을 Lemmix 기준으로 유지합니다.

2/3/4플레인·32폭 폭발 이미지·색상 0 투명도를 지원하고 팔레트와 재생 규칙은 외부에 둡니다. 프레임·좌표·정확한 출력 길이를 검사합니다. 픽셀/해제 출력 길이 오류는 출력을 보존하며 압축 명령 오류는 부분 출력 가능성을 명시합니다. 다른 구간과 원문은 빌릴 수 있습니다.

`no_std`·무할당·I/O 없는 라이브러리와 기존 로컬 의존 하나를 유지했습니다. `inspect_sprites` 호스트 예제와 [스프라이트 검증 매니페스트](../../assets/manifests/lemming_sprites.json)를 추가하고 원본은 Git 추적에서 제외했습니다.
