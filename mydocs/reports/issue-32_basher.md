# G07-02 Basher 결과

이슈: [#32](https://github.com/edwardkim/ohmylemmings/issues/32), 상위 [#1](https://github.com/edwardkim/ohmylemmings/issues/1).

## 구현

Basher 할당/수량·방향별 굴착 마스크·32프레임 이동과 공백/강철/일방통행/낙하·경계 전환을 no_std 코어에 추가했습니다. Digger와 직업 교체가 가능하며 ID 순 지형 관측과 배우별 오류 보존을 유지합니다. 데스크톱 B/D 선택·클릭·원본 스프라이트·수량·정수 ID 재생과 Fun 표준 레벨 선택을 연결했습니다.

## 로컬 검증

- 코어 새9개 테스트와 프레임/방향/바닥/객체1024조합을 통과했습니다. 할당 거부·좌우 마스크·프레임5/21 차이·산술/배치 오류·뒤 배우의 지형 관측을 포함합니다. 네이티브 새2개 행동 테스트도 통과했습니다.
- 실제 Pascal21함수와 합성6사례/12재생/2652상태·모든 삭제 인덱스가 일치하고 SDL142캡처가 픽셀 단위로 일치합니다. 원본 없는 CI에는 이 실행에서 기록한 golden과 자체 합성 마스크만 둡니다.
- 원본 Fun05 네이티브4실행/1244상태/53캡처가 기준 함수 및 SDL readback과 일치합니다. 빠른1/7·실제 DOS pacing의 상태 서명은 `1cce1324786920b393cf41a49b9ce2de604540d376ec4ecd97f9920784622fb0`입니다. 실제 B 키/마우스 입력은 경계168의 ID0으로 기록되어 별도로 기준 재생했습니다.
- 최종 DOS 두 실행3/4의1210샘플·4643게임 영상 프레임에서 수량50→49와 Bashing0x200을 관측했습니다. counter167의 Walking(669,92)→168의 Bashing frame1은 native 입력166의 다음 상태와 대응합니다. 220/260/340 전체320×160 장면×2회는 픽셀 차이가 없습니다. 커서 마스킹/좌표 이동/색 허용 오차를 쓰지 않습니다.
- `make check`의 Rust331개·문서27개·Python41개·포맷/Clippy/빌드·기존 모델/기준·SDL·WASM을 통과했습니다. 기존 원본 F00 서명과 F01 Digger 세 재생/1023상태/135캡처·전체 삭제 서명도 유지했습니다. 원본50개·고정 소스46개를 재검증했습니다.
- [증거 manifest](../../assets/manifests/basher.json)에77소스/833산출물 해시를 고정했습니다. 초기 준비 DOS1/2·native proof1/2는 최종 횟수에서 제외합니다.
