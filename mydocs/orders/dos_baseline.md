# G00-01 DOS 기준판과 원본 리소스 식별·확보

## 목표와 입력

작업 이슈: [GitHub #2](https://github.com/edwardkim/ohmylemmings/issues/2).

상위 이슈는 [#1](https://github.com/edwardkim/ohmylemmings/issues/1)입니다. [전체 구현 계획](../plans/implementation_plan.md)의 첫 작업으로 DOS 원작 VGA 데이터 프로필을 식별하고 검증용 파일을 확보합니다. 사용자는 원본 데이터를 가지고 있지 않으며 에이전트의 확보를 요청했습니다.

## 범위

- 공개 레퍼런스의 원작 데이터 묶음과 부족한 파일을 확보합니다.
- 출처 커밋, 바이트 수, SHA-256을 기록하고 데모와 원작 데이터를 구분합니다.
- 로컬 데이터 검증과 재확보 명령을 제공합니다.
- 기준판의 확인된 정보와 아직 검증하지 않은 항목을 구분합니다.
