게임으로 돌아가기

오디오 라이선스와 소스

이 게임의 OPL 오디오 합성기는 Nuked-OPL3 1.8을 Rust로 이식한 nuked-opl3 0.1.0의 정수 코어를 사용합니다. 라이선스는 LGPL-2.1-or-later입니다.

라이선스 전문 · 이 빌드의 재빌드용 소스 묶음 · 파일 해시

소스 묶음에는 라이브러리와 게임 어댑터의 소스, 고지, 수정 내역, 고정 빌드 파일과 재링크 안내가 들어 있습니다. 게임 데이터는 보유한 원본 파일을 사용합니다.

수정과 재빌드

압축을 풀고 crates/lemmings-opl/README.md를 읽어주세요. 코어와 어댑터를 수정한 뒤 Rust 1.93.1과 Python 3으로 재빌드할 수 있습니다. 라이브러리 수정과 재링크, 해당 수정의 디버깅을 위한 역공학을 허용합니다.

cargo fetch --locked
python3 tools/web_build.py fetch
make web

코어 수정 내역은 crates/lemmings-opl/UPSTREAM.patch에 있습니다. 선택적 스테레오 확장을 끄고 도달하지 않는 부동소수점 팬 계산을 제거했으며, 정수 합성과 레지스터·샘플 순서를 유지합니다. 출력은 OPL2 모노를 사용합니다.
